# 369

Production-grade reproduction of Two26 Studio website with React, Vite, GSAP, and Lenis Smooth Scroll.

## Features
- Full desktop & mobile responsive layout
- Kinetic splash screen & loader animation
- SVG brush stroke masking & interactive cards
- Testimonials card-on-card dynamic stack with mouse follower
- Services animated snake path
- About & Team pages with custom profiles
- Full project case studies
